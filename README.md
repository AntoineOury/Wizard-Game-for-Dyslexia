# Wizard-Game-for-Dyslexia

Two things live in this repository:

- **`Wizard Game/`** — the Unity project (open world, letter-creature mini-game). See the READMEs under
  `Wizard Game/Assets/Scripts/ReadMes/`.
- **`activities/`** — the **Activity Repository**: evidence-based reading exercises digitized as small web
  activities for tablets, built to the *Repository — Vision*, *Activity Corpus*, *Target Units* and
  *Pedagogical Knowledge* documents. Start with `activities/README.md`; the first activity is
  `activities/ort-17-hear-see-tap-letter-g1/` (Hear Letter Name, See Letter, Tap Letter — Letter Unit: Group 1).

  ```sh
  npx --yes http-server activities -p 8080 -c-1   # then open http://localhost:8080/
  ```
